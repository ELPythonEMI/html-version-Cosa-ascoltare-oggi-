# Cosa ascoltare oggi?

Una semplice pagina web che suggerisce a caso un album da ascoltare, pescando da una lista di classici del rock, del metal e della musica italiana. Ogni consiglio apre direttamente una ricerca su YouTube, così puoi iniziare ad ascoltare subito.

## Link per avviare l'app

La pagina è online su GitHub Pages a questo indirizzo:

https://elpythonemi.github.io/html-version-Cosa-ascoltare-oggi-/

## Come funziona

1. Apri il link nel browser.
2. Premi il pulsante "Ci pensa EL".
3. Ti viene proposto un album scelto a caso tra oltre 65 titoli.
4. Cliccando sul link che appare, si apre la ricerca di YouTube con l'album completo già pronto da ascoltare.

Tutto qui. Niente login, niente registrazione, niente pubblicità.

## Cosa trovi nella pagina

Al centro c'è un walkman a cassetta disegnato interamente in CSS 3D. Quando premi il pulsante, le bobine cominciano a girare, il LED rosso si accende e sull'etichetta dorata della cassetta compare il nome dell'album con un effetto macchina da scrivere. Se muovi il mouse sopra il walkman, questo ruote seguendo il cursore, dando un senso di profondità.

La grafica si adatta anche allo schermo del telefono.
